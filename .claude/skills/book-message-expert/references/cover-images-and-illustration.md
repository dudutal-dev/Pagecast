# Cover Images & Original Illustration / תמונת כריכה ואיור מקורי

מטרה: כל תקציר של ספר בודד מלווה בתמונה — **כריכה אמיתית** כשאפשר, **איור מקורי** כשלא. הסקיל לא יכול לארוז תמונות; הוא מגדיר איך לשלוף, לאמת, ומתי ואיך לצייר.

## 1. מתי להציג תמונה / When

- תקציר מלא / עומק / פרק פודקאסט של ספר בודד → תמיד תמונה אחת (כריכה), **אחרי** כותרת הספר ולפני "המסר במשפט אחד".
- המלצות (3–5 ספרים) → כריכות ל-2–3 הראשונים בלבד.
- פלאש, השוואה, שאלה עובדתית ("מי כתב את…"), טקסט בלבד לפי בקשה → בלי תמונה.
- אל תפתח תשובה בתמונה כשהמשתמש שאל שאלה — ענה, ואז המחש.

## 2. שליפת כריכה אמיתית / Fetching a real cover

השתמש ב-`image_search`. שאילתות **באנגלית** (קורפוס גדול יותר), 3–6 מילים, `max_results` 3.

| מקרה | תבנית | דוגמה |
|---|---|---|
| ספר אנגלי | `[Title] [Author] book cover` | `Atomic Habits James Clear book cover` |
| ספר בתרגום לעברית — עדיף המהדורה העברית | `[כותר עברי] [מחבר] כריכה` **או** `[Title] Hebrew edition cover` | `הרגלים אטומיים ג'יימס קליר כריכה` |
| ספר עברי מקורי | `[כותר] [מחבר] ספר כריכה` | `סיפור על אהבה וחושך עמוס עוז כריכה` |
| קלאסיקה עם הרבה מהדורות | הוסף `first edition` או `Penguin edition` | `Meditations Marcus Aurelius Penguin cover` |
| ניסיון שני אם הראשון נכשל | `[Title] paperback front cover` | |

כללים: שאילתה אחת לספר; אם התוצאות הן ממים, סיכומים של אתרי-סיכומים, תמונות מחבר או מהדורות לא נכונות — נסה שאילתה שנייה **פעם אחת**, ואז עבור לאיור. אל תציג יותר מתמונת כריכה אחת לספר.

## 3. אימות / Verification checklist

לפני שמראים כריכה, בדוק מול מה שידוע לך על הספר:
- [ ] הכותר על הכריכה תואם (לא ספר אחר של אותו מחבר, לא "סיכום של", לא "מדריך לימוד").
- [ ] שם המחבר מופיע.
- [ ] זו כריכה קדמית, לא כריכה אחורית/גב/צילום מדף.
- [ ] אם ביקשת מהדורה עברית — הטקסט בעברית.
- [ ] רזולוציה סבירה (רוחב ≥ 300px), לא מטושטש/חתוך.
אם נכשל אחד מהסעיפים — אל תציג, עבור לסעיף 4.

## 4. מתי עוברים לאיור מקורי / When to illustrate

- לא נמצאה כריכה שעברה אימות אחרי שני ניסיונות.
- ספר נדיר / הוצאה עצמית / כתב-יד של המשתמש.
- המשתמש ביקש במפורש "תאייר", "תעצב לי", "תמונה לפרק", "תמונה לפודקאסט".
- באפליקציית הפודקאסט — כשרוצים שפה ויזואלית אחידה לכל הפרקים.

## 5. כללי מקוריות / Originality rules

האיור הוא **יצירה מקורית שמבטאת את המסר**, לא שחזור של הכריכה:
- אל תשחזר את עיצוב הכריכה המקורית — לא הקומפוזיציה, לא הצבעים המזהים, לא הטיפוגרפיה, לא הדימוי המרכזי שלה (למשל: לא לצייר את הנסיך על אסטרואיד קטן עם ורד — זו הכריכה של סנט-אכזופרי; ציירו במקום: מגדלור זעיר בשמיים כחולים, או כוכב אחד בלבד).
- אל תשלב לוגו של הוצאה, ציטוט מהספר, או "מהדורה" מדומה.
- מותר: כותר הספר ושם המחבר כטקסט (עובדות), סמל/מטאפורה של המסר, פלטה משלך.
- סמן תמיד: **"איור מקורי — לא הכריכה המקורית"** (בכיתוב מתחת לתמונה או בשורת התוצאה).
- אל תציע "איך להפוך את זה לדומה יותר לכריכה האמיתית".

## 6. איך מציירים / How to draw

**א. בצ'אט — כלי הוויזואלי (SVG inline):** קרא את מודול `art` (visualize:read_me, platform=mobile כשמדובר בטלפון), וצייר "כרטיס ספר" 3:4 (ראו סעיף 7). הטקסט בעברית — RTL: `direction="rtl"` ו-`text-anchor="end"` או `middle`.

**ב. לקובץ — `scripts/book_card_svg.py`:** מפיק SVG (ואופציונלית PNG דרך cairosvg אם מותקן) עם כותר, מחבר, תחום, סמל מטאפורי מתוך ספריית 14 סמלים (לפי תחום) ופלטה לפי תחום. שימוש:
```
python scripts/book_card_svg.py --title "אדם מחפש משמעות" --author "ויקטור פרנקל" \
  --domain psychology --motif door --out /mnt/user-data/outputs/frankl_card.svg
```
`--motif` אופציונלי (ברירת מחדל לפי תחום). `--subtitle` למסר קצר. `--lang en` לכרטיס באנגלית.

**ג. איור פוטוריאליסטי/אמנותי — Pixa (generate_media):** רק אם מחובר ואם המשתמש רוצה תמונה "אמיתית" לפרק. פרומפט באנגלית, בלי שם הספר בתוך התמונה, בלי סגנון של הכריכה:
```
Editorial illustration expressing the idea "[message in 5–8 words]", [central metaphor object], minimal composition, warm muted palette, soft studio light, no text, no book, no logos, 3:4 portrait, high detail
```
דוגמה ל-*Deep Work*: `Editorial illustration expressing "undivided attention is rare and valuable", a single lit desk lamp in a vast dark library, minimal composition, deep navy and amber palette, soft light, no text, 3:4 portrait`.

## 7. שפת עיצוב אחידה / Visual language for book cards

כדי שהאפליקציה תיראה כמו סדרה אחת:
- **פורמט:** 600×800 (3:4). רקע כהה או שמנת, לא לבן.
- **סמל מרכזי** (קו נקי, 2–3 צבעים) לפי תחום: התפתחות אישית = מדרגות/צעד; פסיכולוגיה = מוח/מנורה; עסקים = מצפן; כסף = עץ/זרע; פרודוקטיביות = שעון חול; זוגיות = שני כיסאות; הורות = יד גדולה ויד קטנה; בריאות = לב פועם/נשימה; רוחניות = מעגל/אגם; פילוסופיה = עמוד יווני/דלת; היסטוריה = מפה/גלגל; מדע = אטום/טלסקופ; ביוגרפיה = דיוקן צללית; ספרות = ציפור/מפתח.
- **טיפוגרפיה:** כותר גדול למעלה (Heebo/Assistant/Arial לעברית), מחבר מתחת, קטן. שורת "המסר" בתחתית — אופציונלי.
- **פלטה לפי תחום** (מוגדרת בסקריפט): התפתחות = כחול-עמוק/זהב; פסיכולוגיה = סגול/שמנת; עסקים = פחם/טורקיז; כסף = ירוק-יער/זהב; זוגיות = בורדו/ורוד-אבקה; הורות = כתום-חם/שמנת; בריאות = ירוק-מנטה/כחול; רוחניות = אינדיגו/לבנדר; פילוסופיה = אבן/טרקוטה; היסטוריה = ספיה/חום; מדע = כחול-לילה/ציאן; ביוגרפיה = שחור/לבן/אדום-נקודה; ספרות = ירוק-יער/זהב-ישן.

## 8. תמונות באפליקציית הפודקאסט

באפליקציה (ראו `podcast-app-spec.md`): לכל פרק שדה `coverUrl` (כריכה אמיתית — קישור) ו-`cardSvg` (איור מקורי מוטמע). ברירת המחדל בתצוגת הרשימה — `cardSvg` (אחיד, ללא תלות ברשת); בעמוד הפרק — `coverUrl` אם קיים, עם כיתוב "כריכה" / "איור מקורי". אל תאחסן תמונות כריכה כ-base64 מהאינטרנט בקובץ (זכויות + גודל) — רק קישור.
