# Hebrew Narration / קריינות התקציר בעברית

מטרה: להפוך תקציר לפרק שמע בעברית טבעית — תסריט שנכתב לאוזן, מעובד להגייה, ומופק בכלי TTS או בדפדפן. לעומק בנושאי TTS (SSML, ניקוד, השוואת ספקים) — הסקיל `hebrew-tts-expert` מרחיב; כאן רק מה שצריך לפודקאסט ספרים.

## תוכן
1. טקסט לעין ≠ טקסט לאוזן
2. תבנית תסריט פרק (4–8 דקות)
3. עיבוד מקדים להגייה
4. הפסקות, קצב וטון (SSML כשנתמך)
5. בחירת קול
6. הפקה: ElevenLabs / OpenAI / Web Speech בדפדפן / סקריפט
7. פרק ארוך: חלוקה לקטעים ותפירה
8. בקרת איכות שמע

---

## 1. טקסט לעין ≠ טקסט לאוזן

| כתוב | מוקרא |
|---|---|
| רשימות ממוספרות, כותרות מודגשות | "הרעיון הראשון… הרעיון השני…" |
| סוגריים, קווים נטויים, אנגלית | הסבר במשפט נפרד; שמות בתעתיק עברי |
| משפטים ארוכים עם פסיקים רבים | משפטים של 8–15 מילים |
| "ראו טבלה" | "בואו נחשוב על זה רגע" |
| מסר פעם אחת | מסר 3 פעמים: פתיח, אמצע, סיום — בניסוחים שונים |
| "המחבר טוען" | "קליר אומר… ותשימו לב למה שהוא **לא** אומר" |

## 2. תבנית תסריט פרק / Episode script template

```
[אינטרו · 20–40 שנ']
שלום, ברוכים הבאים ל"[שם הפודקאסט]". אני [שם הקריין/Claude], והיום נדבר על "[כותר]" של [מחבר בתעתיק]. [משפט אחד מה מיוחד בספר]. והמשפט שאני רוצה שתצאו איתו הוא זה: [המסר].

[רקע · 30–60 שנ']
[מי המחבר, מה קרה שגרם לו לכתוב, שנת פרסום במילים.]

[גוף · 3–5 רעיונות · 40–90 שנ' כל אחד]
הרעיון הראשון. [שם הרעיון]. [הסבר בשני-שלושה משפטים.] [הדוגמה של המחבר.] [מה זה אומר לכם — משפט.]
(מעבר) וזה מביא אותנו לרעיון השני…

[הסתייגות · 20–30 שנ']
עכשיו, כמו בכל ספר, יש גם ביקורת. [ביקורת מקובלת.] לדעתי, [דעה מסומנת].

[סיום · 20–30 שנ']
אז אם לוקחים משהו אחד מ"[כותר]", זה זה: [המסר בניסוח שני]. [צעד אחד לשבוע.] תודה שהאזנתם. [בפרק הבא — אופציונלי.]
```
אורך: 600–1,100 מילים. קצב קריינות עברית: ~140–160 מילים לדקה.

## 3. עיבוד מקדים להגייה / Preprocessing

הרץ על התסריט לפני שליחה ל-TTS (הסקריפט `narrate_summary.py` עושה את הבסיס אוטומטית):
- **שמות לועזיים → תעתיק:** James Clear → ג'יימס קליר; Kahneman → כהנמן; Viktor Frankl → ויקטור פרנקל; Nassim Taleb → נסים טאלב. כותרי ספרים באנגלית → הכותר העברי, ואם אין — תעתיק + "באנגלית".
- **מספרים → מילים:** 2018 → "אלפיים ושמונה עשרה"; 1% → "אחוז אחד"; 10,000 → "עשרת אלפים". מספרים בתסריט הם המקום הכי נפוץ לשגיאות TTS בעברית.
- **ראשי תיבות:** ד"ר → דוקטור; רו"ח → רואה חשבון; ארה"ב → ארצות הברית.
- **סימנים:** — → פסיק או נקודה; "…" → נקודה; מירכאות → הסר (או השאר אם הקול מטפל).
- **מילים דו-משמעיות** (ספר/סָפַר, מלך/מָלַך): נסח מחדש כדי שההקשר יכריע, או הוסף ניקוד למילה הבודדת.
- **אנגלית שנשארת** (שמות מוצרים/מותגים): עטוף ב-`<lang xml:lang="en-US">` כשיש SSML; אחרת תעתיק.

## 4. הפסקות, קצב וטון

| מקום | הפסקה | הערה |
|---|---|---|
| אחרי המסר בפתיח | 700ms | תן לזה לשקוע |
| בין רעיונות | 600ms | |
| בין משפטים | ברירת מחדל של המנוע | אל תוסיף ידנית |
| לפני "לדעתי" / הסתייגות | 500ms + קצב איטי יותר 5% | מסמן החלפת שכבה |
| לפני המשפט האחרון | 800ms | |

SSML (Azure/Google): `<break time="700ms"/>`, `<prosody rate="95%">`. ElevenLabs: השתמש בסימני פיסוק ושורות ריקות (השהיה); `<break time="0.7s" />` נתמך במודלים החדשים. OpenAI TTS: ללא SSML — שלוט דרך פיסוק ו-`instructions` (מודל gpt-4o-mini-tts).

## 5. בחירת קול / Voice

- ברירת מחדל לפודקאסט ספרים: קול **חם, בינוני, לא-רדיופוני**, מהירות 0.95–1.0. גבר או אישה לפי העדפת המשתמש — שאל פעם אחת ושמור בהעדפות האפליקציה.
- ספר רגיש (טראומה, אובדן) — קצב 0.9, ללא "אנרגיה".
- ספרות יפה — מעט יותר אקספרסיבי; אין "קולות" לדמויות (זה פודקאסט, לא הצגה).
- ElevenLabs: קולות multilingual v2 / v3 עם תמיכה בעברית; בדוק דוגמה של 20 שניות לפני פרק שלם.
- Web Speech בדפדפן: `speechSynthesis.getVoices().filter(v => v.lang.startsWith('he'))` — קיים ב-Chrome/Edge (Google עברית), Safari/iOS ("Carmit"). איכות בסיסית אבל אפס עלות ואפס רשת — ברירת המחדל של האפליקציה.

## 6. הפקה / Production

**סקריפט:** `scripts/narrate_summary.py` — קורא תסריט (txt/md), מעבד מקדימה, ושולח ל-ElevenLabs (`ELEVENLABS_API_KEY`) או OpenAI (`OPENAI_API_KEY`), מייצר MP3 ל-`/mnt/user-data/outputs/`. בסביבה ללא גישה ל-API של הספקים (כמו הסנדבוקס כאן) — הסקריפט מייצר את התסריט המעובד + קובץ SSML ומסביר למשתמש להריץ מקומית.
```
python scripts/narrate_summary.py script.md --provider elevenlabs --voice "<voice_id>" --out /mnt/user-data/outputs/frankl.mp3
python scripts/narrate_summary.py script.md --provider openai --voice alloy --out frankl.mp3
python scripts/narrate_summary.py script.md --dry-run   # רק עיבוד + SSML
```

**בדפדפן (בלי מפתחות):** נגן HTML יחיד — כפתור "השמע", `SpeechSynthesisUtterance` עם `lang='he-IL'`, בחירת קול עברי אם קיים, שליטה במהירות, הדגשת המשפט הנוכחי. תבנית מוכנה: `assets/player-template.html` (העתק, הכנס את התסריט למשתנה `SCRIPT`, שמור ל-outputs, הצג עם present_files).

**בצ'אט בטלפון:** אין הפקת שמע ישירה — תן את התסריט + קובץ הנגן HTML; המשתמש פותח ולוחץ "השמע".

## 7. פרק ארוך / Long episodes

ElevenLabs/OpenAI מגבילים ~4,000–5,000 תווים לבקשה. חלק לפי `[כותרות הקטעים]` בתסריט, הפק כל קטע, ותפור עם ffmpeg:
```
ffmpeg -f concat -safe 0 -i list.txt -c copy episode.mp3
```
הסקריפט עושה זאת אוטומטית (`--max-chars 4000`).

## 8. בקרת איכות שמע / QA

- האזן ל-30 השניות הראשונות: שם המחבר נשמע נכון? המספרים? אם לא — תקן תעתיק ולא את הקול.
- בדוק שאין "הדגשות" אקראיות במילים עבריות (בעיה ידועה) — לרוב נפתר בהוספת פסיק לפני המילה.
- אורך: 4–8 דקות לפרק; מעל 10 — חלק לשני פרקים.
- שמור לצד ה-MP3 את התסריט הסופי (`.md`) — זה מה שהאפליקציה מציגה כ"טרנסקריפט".
