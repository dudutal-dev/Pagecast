# Podcast App Spec / אפיון אפליקציית "פודקאסט הספרים שלי"

מטרה: אפליקציה לשימוש אישי — ספרייה של תקצירי ספרים שכל אחד מהם הוא "פרק": טקסט + תסריט + הקראה + כריכה/איור. קובץ HTML יחיד, עברית RTL, עובד בטלפון ובמחשב, ללא שרת. נבנית לפי מוסכמות הכלים של דודו (קובץ יחיד, שמירה מקומית, ייצוא/ייבוא JSON) ולפי `ui-ux-pro-max` לעיצוב. לפני בנייה — קרא גם `/mnt/skills/user/app-builder/SKILL.md`.

## 1. עקרונות

- קובץ אחד: `book-podcast.html` ב-`/mnt/user-data/outputs/`. ללא build, ללא תלות ב-CDN חובה (חוץ מגופן אופציונלי).
- כל הנתונים ב-`localStorage` (מפתח `bookpod:v1`) + ייצוא JSON ידני. **שים לב:** ב-artifacts של claude.ai localStorage לא זמין — במקרה כזה state בזיכרון + ייצוא/ייבוא; הקובץ שנשמר ל-outputs ונפתח מקומית כן תומך ב-localStorage.
- הקראה: ברירת מחדל Web Speech API (חינם, אופליין); אופציונלי — הדבקת מפתח ElevenLabs/OpenAI בהגדרות והפקת MP3 שמאוחסן כ-Blob URL לסשן / הורדה.
- שפה: עברית RTL; כותרים באנגלית מוצגים LTR בתוך span עם `dir="ltr"`.
- כל פרק = הפלט של הסקיל הזה (תקציר מלא + תסריט + כריכה/איור), כך שאפשר להוסיף פרקים גם מהצ'אט (הדבקת JSON) וגם מתוך האפליקציה.

## 2. מסכים

1. **הספרייה (ראשי)** — רשת כרטיסים 2 בטור בטלפון / 4 במחשב: איור/כריכה, כותר, מחבר, תחום (צ'יפ), משך משוער, סטטוס (לא הושמע / באמצע / הושמע). חיפוש חופשי + סינון לפי תחום + מיון (נוסף לאחרונה / א"ב / משך). כפתור צף "＋ פרק חדש".
2. **הפרק** — כריכה גדולה, כותר, מחבר, שנה, תחום; שורת "המסר במשפט אחד" מודגשת; נגן (סעיף 4); לשוניות: *תקציר* (הטקסט המעוצב) / *תסריט* (טקסט הקריינות, המשפט הנוכחי מודגש בזמן השמעה) / *לקחת הביתה* (3 צעדים כ-checklist שנשמר) / *הערות שלי*. כפתורים: מועדף ⭐, סמן כהושמע, שתף (העתקת טקסט), מחק.
3. **פרק חדש** — שלוש דרכים: (א) הדבקת JSON שהצ'אט ייצר; (ב) טופס ידני; (ג) "צור עם AI" — שדה כותר+מחבר → קריאה ל-Anthropic API (סעיף 5) → תצוגה מקדימה → שמירה.
4. **פלייליסטים** — "מסלול" (למשל "כסף למתחילים"): רשימה מסודרת של פרקים, השמעה רציפה.
5. **הגדרות** — קול (רשימת קולות עבריים זמינים במכשיר), מהירות (0.8–1.3), גובה; מפתחות API (נשמרים מקומית בלבד, אזהרה); שם הפודקאסט והקריין (משמש בפתיח); ייצוא/ייבוא; ניקוי נתונים.

## 4. נגן ההקראה / Player

- Web Speech: פצל את `script` למשפטים (regex על `. ! ?` + שורות ריקות), הזן `SpeechSynthesisUtterance` משפט-משפט (עוקף מגבלת אורך של Chrome ומאפשר הדגשה ו-progress). `lang='he-IL'`, `voice` מההגדרות, `rate/pitch`. כפתורים: השמע/השהה, ⏪ 15 שנ' (משפטים), ⏩, מהירות. שמור `progressSec` (אינדקס משפט) כל 5 שניות.
- אם `audioUrl` קיים (MP3 שהופק) — `<audio>` רגיל עם אותם כפתורים; הדגשת משפט לפי הערכת זמן (מילים לדקה) — "בערך".
- מצב "השמעה רציפה" לפלייליסט: בסיום פרק → הבא, עם השהיה של 2 שניות וג'ינגל קצר (אופציונלי, WebAudio).
- מסך נעול/רקע בטלפון: Web Speech ממשיך ב-iOS רק כשהאפליקציה בחזית — הודע למשתמש; ל-MP3 השתמש ב-MediaSession API כדי להציג כותר ולאפשר שליטה מהמסך הנעול.

## 5. ייצור פרק חדש מתוך האפליקציה / AI generation

קריאה ל-`https://api.anthropic.com/v1/messages` (בקובץ artifact — בלי מפתח; בקובץ מקומי — המשתמש מזין מפתח בהגדרות ומוסיף כותרת `x-api-key` ו-`anthropic-dangerous-direct-browser-access: true`). מודל: הסונט העדכני. system prompt = גרסה מקוצרת של SKILL.md (עקרונות + תבנית התקציר + תבנית התסריט + כללי דיוק וציטוט), ובקשה להחזיר **JSON בלבד** במבנה Episode (ללא coverUrl/cardSvg). האפליקציה מייצרת `cardSvg` בעצמה מפונקציית JS שמשקפת את `book_card_svg.py` (אותם סמלים ופלטות), ומציעה למשתמש להדביק `coverUrl` ידנית. כללי הבטיחות והזכויות (ללא ציטוטים ארוכים, סימון דעה, "מצב הידע היום") נכנסים ל-system prompt.

## 6. שמירה, ייצוא, ייבוא

- `localStorage` אוטומטי אחרי כל שינוי (debounce 500ms) + כפתור "ייצא JSON" (הורדת `bookpod-backup-YYYY-MM-DD.json`) + "ייבא JSON" (מיזוג לפי `id`; חדש דורס ישן אחרי אישור).
- ייצוא פרק בודד כ-Markdown (התקציר + התסריט) — לשיתוף.
- גודל: `cardSvg` קטן (~3–8KB); `coverUrl` קישור בלבד; MP3 לא נשמר ב-localStorage (רק קישור להורדה בסשן).

## 7. עיצוב

- לפי `ui-ux-pro-max`: סגנון "ספרייה שקטה" — רקע כהה חם (#14110F) או שמנת (#F5F0E8) עם מצב לילה; אקסנט זהב-ישן (#C9A961); כרטיסים עם צל רך; גופן Heebo/Assistant (fallback Arial). כותרים באנגלית ב-Inter.
- כרטיס פרק = איור 3:4 + טקסט; מיקרו-אנימציה עדינה בהשמעה (גל שמע/נקודה פועמת).
- נגישות: כפתורי נגן ≥ 44px, ניגודיות AA, `aria-label` בעברית, ניווט מקלדת.
- ריק (empty state): "עדיין אין פרקים — הדבק פרק מהצ'אט או צור אחד עם AI", עם כפתור.

## 8. שלבי בנייה ו-QA

1. שלד HTML + state + localStorage + ספרייה ריקה → שמור ל-outputs (שמירת ביניים, דווח).
2. מסך פרק + נגן Web Speech (משפט-משפט) → בדוק עם תסריט הדוגמה של "אדם מחפש משמעות" → שמור.
3. הוספת פרק: JSON / ידני / AI → שמור.
4. פלייליסטים + הגדרות + ייצוא/ייבוא → שמור.
5. עיצוב סופי, מצב לילה, נגישות → QA לפי `generic-application-validation`: 3 פרקים בתחומים שונים, כותר באנגלית, ספר ללא כריכה, טקסט ארוך (1,500 מילים), אין קול עברי במכשיר (fallback לקול ברירת מחדל + הודעה), ייבוא JSON פגום.
6. מסירה: `present_files` על הקובץ + הוראות פתיחה בטלפון (שמור ב"קבצים", פתח ב-Safari/Chrome; "הוסף למסך הבית").
